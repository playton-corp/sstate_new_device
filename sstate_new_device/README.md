# S.State Group

Адаптивный журнал класса с отдельными кабинетами учителя и учеников. Данные оценок не публикуются в браузере без авторизации.

## Развёртывание на Node-хостинге

Приложению нужен Node.js 20+ и постоянное хранилище для `journal-data.json`. При запуске задайте переменные окружения в панели хостинга:

- `SSTATE_TEACHER_PASSWORD` — пароль учителя, не короче 12 символов.
- `SSTATE_STUDENTS` — JSON-массив учеников, например `[ {"id":"student_a1","name":"Имя ученика"} ]`.
- `SSTATE_STUDENT_PASSWORDS` — JSON-объект паролей по id, например `{ "student_a1":"уникальный-длинный-пароль" }`; каждый пароль не короче 12 символов.
- `SSTATE_DATA_FILE` — путь на постоянном диске, например `/var/data/journal-data.json` (зависит от хостинга).

Не добавляйте реальные имена, пароли, `.env` или файл журнала в Git. Создайте постоянный диск на хостинге и укажите его путь в `SSTATE_DATA_FILE`: временный диск бесплатных веб-сервисов может очищаться при перезапуске/публикации.

Команда сборки не нужна. Команда запуска: `npm start`. Для доступа к журналу используйте корневой URL сервиса; личные страницы открываются в формате `/sstate-for-pupils/current/<id>/view/account`.

Сервер хранит сессии в памяти; после перезапуска пользователям нужно войти повторно. Оценки сохраняются на указанном постоянном диске.
